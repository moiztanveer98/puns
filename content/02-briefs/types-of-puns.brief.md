## Contextual structure

- **Intro**: sentence 1 states there are 7 main types of puns, named inline in
  the order they appear below. Sentence 2 states what distinguishes a type
  (the mechanism: sound, spelling, structure, or form).
- **Each type section (H2)**: first sentence = direct definition using the
  pattern "[Type] puns are puns that [mechanism]." Second sentence = one
  concrete example with the mechanism labeled. Each links to its own dedicated
  page using the type's exact name as anchor text (e.g. "homophonic puns").
- **Which Type Is Easiest? (H3, comparative)**: names homophonic puns as the
  most common starting point for new pun-writers, links to the how-to guide.
- Each type definition must be internally consistent with its own dedicated
  page's definition (no conflicting data across the site, per §6.5).
