# Document Template: Use-Hub Page (OUTER)

Applies to the 6 P1 use-hub pages. These are OUTER pages: CE (puns) + one
predicate of the CSI (a single *use*, cutting across every topic) rather than
the full topic+use matrix a CORE page covers. Their job is to curate the
strongest lines across topics and link heavily back into CORE topic pages —
per §4.1, OUTER's purpose is "historical data, sessions, queries, relevance,"
not standalone authority. Unlike CORE topic pages, these ARE link-heavy.

## Competitor slots (generic — page-specific briefs may override slot 1)

1. **Top-ranking, comprehensive page** — Flick's caption pages (for Captions),
   otherwise the closest Punpedia use-based collection page.
2. **Source to outrank** — a generic "best puns" listicle site with no topic
   organization — the format CraftyPuns is positioned against.
3. **Phrase-taxonomy source** — Punpedia's topic pages, mined for which topics
   contribute the strongest lines for this particular use.

Macro section is organized by topic grouper (e.g. Animal / Food / Holiday), not
a flat list — this is what makes the page a genuine curation rather than a
copy of a single topic page, and it's where most internal links to CORE topic
pages belong, since every curated line should link back to its source topic page.

## Contextual structure

- **Intro**: states the use-hub's format rule in sentence 1 (e.g. "Instagram
  caption puns stay short — under 8 words — so they read in a glance under a
  photo."), then sentence 2 states how the page is organized (by topic).
- **Topic grouper sections**: 3–4 per page, each a themed cluster (e.g. Animal,
  Food, Holiday) pulling 8–12 lines curated from across the matching topic
  pages' own matching H2 section (per the sheet's "Pulls From / Links To"
  column). Each cluster's intro sentence links to 2–3 of its source topic pages
  using the topic's own page title as anchor text.
- **FAQ**: same 3-question pattern as topic pages (definitional, boolean,
  definitional), format rule and boolean question are use-hub-specific — see
  each page's own brief.
- **More Ways to Use Puns**: links to 2–3 sibling use-hub pages, descriptive
  anchors matching their titles.

## Writing rules

Same as the topic-page template (§6 of the framework): answer-first present
tense in FAQ, no modality unless the question carries it, list items carry the
context term, no external links, complete-sentence list intros.
